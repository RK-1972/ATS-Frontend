# Workforce Planning — Help videos

Place MP4 files in this folder using the filenames referenced in
`src/help/content/workforcePlanningHelpTopics.js`.

| File | Topic |
|------|--------|
| `wp-overview.mp4` | Workforce Planning Overview |
| `wp-budget-requests-exceptions.mp4` | Budget Requests & Budget Exceptions |
| `wp-approval-position-requisition.mp4` | Approval → Approved Position → Requisition |
| `wp-dashboard-analytics.mp4` | Dashboard & Analytics |

The Help drawer probes each file at runtime. **Watch video** appears only when the file is present and reachable at `/help/workforce-planning/<filename>`.
