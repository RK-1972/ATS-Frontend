# Requisitions — Help videos

Place MP4 files in this folder using the filenames referenced in
`src/help/helpManifest.js`.

| File | Topic |
|------|--------|
| `req-create-basics.mp4` | Creating a requisition (`req-create-basics`) |

The Help drawer probes each file at runtime. **Watch video** appears only when the file is present and reachable at `/help/requisitions/<filename>`.
